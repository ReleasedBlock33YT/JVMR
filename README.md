# JVMR
A (hopefully) good replacement to the Java virtual machine

## Current features
Review [the roadmap](https://github.com/ReleasedBlock33YT/JVMR/wiki/Roadmap) on the Wiki to see the roadmap.
Implemented features:
* NIO file mutation support
* java.io.file compat.
* Archive compat.
* JAR compat.
* JarFile compat.
* NIO directory discovery support
* NIO stream factory support
* NIO path compat.
* Class-loader support
* .jar launching
